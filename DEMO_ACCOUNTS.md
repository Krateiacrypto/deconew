## 📝 Notlar

### Otomatik Oluşturma Scripti

Eğer manuel kayıt yerine toplu oluşturmak isterseniz, aşağıdaki script'i kullanabilirsiniz:

```typescript
// src/scripts/createDemoAccounts.ts
import { supabase } from '../lib/supabase';

const demoAccounts = [
  {
    email: 'superadmin@decarbonize.world',
    password: 'Demo123!@#',
    name: 'Super Admin',
    role: 'superadmin'
  },
  // ... diğer hesaplar
];

async function createDemoAccounts() {
  for (const account of demoAccounts) {
    try {
      const { data, error } = await supabase.auth.signUp({
        email: account.email,
        password: account.password,
        options: {
          data: {
            name: account.name,
            role: account.role
          }
        }
      });

      if (error) {
        console.error(`Failed to create ${account.email}:`, error);
      } else {
        console.log(`✅ Created: ${account.email}`);
      }
    } catch (err) {
      console.error(`Error creating ${account.email}:`, err);
    }
  }
}

createDemoAccounts();
```

### Supabase Dashboard'dan Oluşturma

1. Supabase Dashboard > Authentication > Users
2. "Add User" butonuna tıklayın
3. Email ve password girin
4. "Auto Confirm Email" seçeneğini işaretleyin
5. "Create User" ile oluşturun
6. Oluşturulan user'ın ID'sini kopyalayın
7. Database > Table Editor > users tablosuna gidin
8. İlgili user ID ile profil bilgilerini güncelleyin
